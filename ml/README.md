# ML-модуль Core V3.0 — Shadow Engine v0.3

> «Стажёр, который учится думать как правила»

---

## Что это

Shadow Engine — параллельный движок, который **объясняет решения
жёстких правил** в `core/kv_analyzer.py`, а не заменяет их.

Он НЕ влияет на итоговую выгрузку ревизора. Он работает **рядом**,
собирая датасет «признаки → причина → уверенность» для будущей
ML-модели (Stage 4 из roadmap).

**Цель:** imitation learning. Модель учится **повторять** решения
правил, а потом — **превосходить** их.
